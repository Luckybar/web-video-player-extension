🎬 單手影片控制器

在手機上單手更容易控制網頁影片。以下兩種安裝方式擇一即可。

方式 A 手機 Chrome ‧ 書籤小工具(推薦)

手機版 Chrome 無法裝擴充功能,但可以用「書籤」達成一樣的效果。因為手機沒辦法直接把按鈕拖到書籤列,請照下面步驟用「複製網址」的方式建立:

  1. 先點下面的按鈕,把整段程式碼複製起來:
    已複製 ✓
  2. 在手機 Chrome 隨便一個網頁,點右上角 ⋮ → 星號 ☆ 把它加入書籤。
  3. 再點 ⋮ → 書籤,找到剛剛那個書籤,點旁邊的 編輯(鉛筆)。
  4. 把「網址」欄位整個清空,貼上剛剛複製的程式碼,名稱可改成「單手控制」,存檔。
  5. 之後在任何有影片的網頁,於 網址列輸入「單手控制」,點出現的那個書籤,控制列就會從畫面下方跳出來 🎉

💡 小訣竅:在網址列打書籤名字前幾個字,Chrome 就會把它列出來,點一下即可執行。再點一次可收起控制列。

方式 B 擴充功能(需支援的瀏覽器)

若你願意換到支援擴充功能的瀏覽器,可直接安裝 extension/ 資料夾:

桌面 Chrome / Edge網址列輸入 chrome://extensions → 開「開發人員模式」→「載入未封裝項目」→ 選 extension 資料夾。
Kiwi Browser(Android)右上 ⋮ → Extensions → 開「開發人員模式」→「＋ (from .zip/.crx/folder)」→ 選 extension 資料夾或壓縮檔。
Quetta Browser(Android)設定 → 擴充功能 → 由 Chrome 線上應用程式商店或本機載入。

裝好後,點瀏覽器工具列的 🎬 圖示即可叫出/收起控制列(再點一次收起)。
