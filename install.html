推薦 手機 Chrome ‧ 短版 loader 書籤

手機 Chrome 存「超長」書籤會被截斷、導致沒反應。建議用這個約 230 字的短 loader,它會從 CDN 載入最新的 controller.js(你之後改功能、推上 GitHub 就會自動更新):

  1. 複製 bookmarklet/loader.txt 的整段內容(或點下面按鈕):
    已複製 ✓
  2. 手機 Chrome 任一網頁 → 右上 ⋮ → 星號 ☆ 加入書籤。
  3. ⋮ → 書籤 → 找到它 → 編輯 → 把「網址」清空貼上,名稱改「單手控制」,存檔。
  4. 影片頁在網址列輸入「單手控制」點它 → 控制介面出現。再點一次收起。

⚠️ 推上 GitHub 後,jsDelivr 對 @main 快取最長約 12 小時。想馬上更新可開一次:
https://purge.jsdelivr.net/gh/Luckybar/web-video-player-extension@main/src/controller.js
