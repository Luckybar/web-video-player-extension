🎬 單手影片控制器

左右兩大塊觸控區,單手就能控制影片。中間留一條縫給你點原生的播放/暫停。

🕹️ 怎麼操作

⏪
點=倒退30s
長按=放慢
中間
原生控制
⏩
點=快轉30s
長按=加速
右塊 · 點一下快轉 30 秒
右塊 · 長按臨時 2 倍速快進,放開手指回到原速
左塊 · 點一下倒退 30 秒
左塊 · 長按臨時 0.5 倍速慢放,放開回原速
中間縫不攔截,照常點影片叫出原生播放/暫停
底部小膠囊暫時關閉/開啟觸控區(需要捲動網頁時用)

方式 A 手機 Chrome ‧ 書籤小工具(推薦)

  1. 點下面按鈕複製程式碼:
    已複製 ✓
  2. 手機 Chrome 任一網頁 → 右上 ⋮ → 星號 ☆ 加入書籤。
  3. ⋮ → 書籤 → 找到它 → 編輯(鉛筆)。
  4. 把「網址」欄清空,貼上剛複製的程式碼,名稱改成「單手控制」,存檔。
  5. 之後在影片頁,網址列輸入「單手控制」點它一下 → 左右觸控區出現 🎉 再點一次可收起。

💡 網址列打前幾個字 Chrome 就會列出書籤,點一下即可。

方式 B 擴充功能(需支援的瀏覽器)

桌面 Chrome / Edgechrome://extensions → 開「開發人員模式」→「載入未封裝項目」→ 選 extension 資料夾。
Kiwi Browser⋮ → Extensions → 開發人員模式 → 從資料夾/zip 載入。
Quetta Browser設定 → 擴充功能 → 本機載入。

裝好後點工具列 🎬 圖示開啟/收起。

關於長按加速:採「按住臨時變速、放開回原速」的方式(像 YouTube 按住 2x),不會改動你原本的播放速度設定。
